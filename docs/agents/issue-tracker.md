# Issue Tracker

Platform: GitHub
Tool: `gh` CLI

## How issues are created

- `gh issue create` from the repo root
- Issues use the repo's default issue template

## How issues are referenced

- By number: `#123`
- Skills like `triage`, `to-tickets`, and `to-spec` read/write issues via `gh`

## PRs as a request surface

Disabled by default. External PRs are not triaged unless this flag is enabled.
