# Triage Labels

Canonical role labels (defaults):

| Role | Label |
|------|-------|
| Triage | `needs-triage` |
| Info needed | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

These labels are used by the `triage` skill to classify issues.
